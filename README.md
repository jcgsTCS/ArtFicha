# ArtFicha

Aplicación full-stack que utiliza IA y APIs para generar metadatos de productos y automatizar su publicación, reduciendo los cuellos de botella manuales.

## Descripción

ArtFicha permite generar automáticamente títulos, descripciones y categorización de productos a partir de imágenes y datos básicos proporcionados por el usuario.

El sistema utiliza inteligencia artificial para analizar el contenido y generar información optimizada lista para ser publicada en plataformas externas.

## Funcionalidades principales

- Generación automática de títulos y descripciones con IA
- Clasificación y categorización de productos
- Flujo completo desde input del usuario hasta publicación
- Integración con APIs externas

## Tecnologías

- Frontend: React + TypeScript
- Backend: Supabase / Edge Functions
- IA: Integración con modelos de lenguaje
- Base de datos: Supabase

## Objetivo

Reducir el trabajo manual en la creación de fichas de producto y mejorar la eficiencia en procesos de publicación.

## Notas

Este proyecto está en desarrollo y enfocado a aprendizaje y experimentación con flujos reales de negocio.
